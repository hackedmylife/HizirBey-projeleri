# Project delivery policy

The user has authorized publishing final versions of these projects to
`hackedmylife/HizirBey-projeleri`, including future changes.

- Keep projects in separate folders. Update source, assets, build instructions,
  version notes and relevant install packages together.
- Never commit token/API key files, sessions, private keys or user data.
- Preserve local credentials on updates. Do not distribute placeholder files
  that overwrite a user's existing credentials.
- Inspect archives as well as loose files for literal credentials before pushing.
- Verify syntax and appropriate build checks. State any untested behavior.
- Anne TV and SmartTube have their own repositories and update systems;
  preserve those systems and link to the canonical repositories here.
- Do not call an older source snapshot the latest release if it cannot be
  matched to the latest available binary.
